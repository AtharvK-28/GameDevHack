# Credits

Every third-party asset in the game, where it came from, and its licence. This file is also the in-game Credits screen. Raw downloads go in `assets/_incoming/` (ignored by Git and Godot); only the pieces the game uses are copied into the project.

## Game

### Ghosted Movers
Made for the Artificial Arcade hackathon (PS02: Chaos Control).  
Mover and ghost characters: the team's own models (`assets/models/mover/`, `assets/models/ghost/`).  
Surface textures, portraits, cobweb and ghost icon: made by the project's own `tools/` scripts.  
Wildlife (crows, bats, cat, rats, frogs, owl), the scarecrow, mailbox and hydrant: built from simple shapes in `arenas/dressing/`.  
Synthesized in `autoload/Sfx.gd`: the banking chime, night ambience, thunder, owl, howl and crows; the tumble boing, possession theremin and sad trombone; and the intro's goat, whoosh, rumble, walkie crackle and organ chord.

## Ghost Ship

- Kenney Pirate Kit 2.1, https://opengameart.org/content/pirate-kit — CC0; original licence in `models/pirate/kenney/license.txt`. Selected GLBs and their required `Textures/colormap.png`; all under 5000 triangles each. Runtime-used models: ship-pirate-large (1938 triangles, the galleon since decision 107), chest (232), barrel (148), crate (76), boat-row-large (174), tower-complete-small (650).
- Original hull, tug, small valuables, anchor, lantern, tarp, and stylised fallback water: project-created native geometry/code.
- Quaternius supplied `pirate_kit_70_models.glb`: inspected only, NOT distributed/imported. Embedded metadata says Sketchfab Standard (source https://sketchfab.com/3d-models/pirate-kit-70-models-52af2bc5ac5846ff84a0d671b897c0a2); 1040540 triangles in 39 meshes. The original https://quaternius.com/packs/piratekit.html lists CC0 while the current general licence page lists QAL; the supplied file has not been relabelled CC0.
- Water reference evaluated and NOT shipped: MinhCreatorVN, incorporating kmitt91 and StayAtHomeDev, https://godotshaders.com/shader/stylized-water-for-godot-4-x/ — MIT code, but the textures it needs are not MIT. Rendered side by side against our own shader on 2026-10-25; without those textures it renders as ice floes, so it was removed from `assets/` and the ship keeps the original `ship_water.gdshader`.
